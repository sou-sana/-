「除雪機を買うと、札幌市から補助が出る」と聞いたことはありませんか。札幌市には小型除雪機の購入費を補助する制度がありますが、**個人で買う除雪機は対象になりません**。市の公式ページで、対象と条件を確かめました。

## 先に結論

| 質問 | 答え（札幌市公式） |
|---|---|
| 個人で買う除雪機に補助は出る？ | **出ない**。個人と企業への補助は行っていない |
| 誰が対象？ | 町内会と、除雪ボランティアを行う団体 |
| どんな機械が対象？ | 安全装置付きのハンドガイド型（歩いて押すタイプ）の小型除雪機で、販売業者から買う新品 |
| いくら出る？ | 本体価格（消費税込み）の**2分の1以内、上限50万円** |
| いつ申し込む？ | 2026年度（令和8年度）は**9月16日に受付開始**（予算に達し次第締め切り。今も受付中かは雪対策室に確認）。**購入する2週間以上前**に申し込む |

## 1. 個人は対象外

札幌市の「小型除雪機購入費の補助」は、地域の除雪を支える団体のための制度です。市の公式ページには、**個人と企業への補助は行っていない**と書かれています。

自宅の前や駐車場を除雪するために個人で買う場合は、この補助は使えません。

補助を受けた除雪機は、**市道で行う地域の除雪**に使うのが基本です。使い方の例として、雪山で狭くなった生活道路の幅を広げる、市が除雪しない生活道路の除雪、高齢者や障がい者の家の周りの除雪、消火栓やごみステーションの周りの除雪が挙げられています。自分の家の敷地だけを除雪する目的には合いません。

## 2. 町内会で買うなら：条件と注意点

町内会や除雪ボランティアの団体で除雪機を買う場合は、次の点に注意してください（札幌市公式ページの記載）。

| 項目 | 内容（令和8年度） |
|---|---|
| 補助額 | 購入金額の2分の1以内（上限50万円）。消費税は含むが、オプション部品・付属品・配送料などは含まない |
| 対象の機械 | 安全装置付きのハンドガイド型小型除雪機。販売業者から買う新品（個人売買・中古は対象外） |
| 申し込み | **購入する2週間以上前**に、持参・郵送・電子メールで提出（ファクスは不可） |
| 受付 | 2026年9月16日から。予算に達し次第締め切り、多いと抽選の場合あり |
| 使い方の条件 | 市道で行う地域の除雪が基本。3年度の間、地域の除雪に使い、毎年度1回以上「使用実績報告書」を出す |
| その他 | 交付が決まる前に買うと補助は出ない／営利目的で使わない／一度補助を受けた団体は、その後6年間は再び補助を受けられない／「小型除雪機貸出制度」との重複利用は不可 |

申込書類は、申請書（様式1）、購入予定の機械の見積書と仕様書（カタログなど）、除雪する場所の地図（使用目的も書く）、誓約書（様式6）です。

**町内会がない地域では？** 要綱では、町内会のほか「その地域の除雪を行うために作られた組織」も対象です。新しく作る場合は、原則として同じ地域に住む3世帯以上で構成し、規約と名簿を作り、作業する道路沿いの地権者の半数以上から同意書をもらう必要があります。詳しくは雪対策室計画課（011-211-2682）に問い合わせてください。

作業中の事故は使用者の責任になるため、市は「ボランティア活動保険」などへの加入を勧めています。

## 3. 「貸出制度」もある（団体向け）

札幌市には、除雪機を買うのではなく**借りる**制度（小型除雪機貸出制度）もあります。これも町内会などの団体向けで、購入費の補助とは重複して使えません。団体で「まず使ってみたい」場合は、こちらも比べてみてください。

## 札幌市以外に住んでいる人へ

除雪機の補助は、市町村ごとに対象や条件がまったく違います。個人が対象になる市町村があるかどうかは、この記事では確かめていません。お住まいの市町村のホームページで「除雪機 補助」と検索するか、役所に問い合わせてください。

## 使うときの注意

除雪機を使うときは、取扱説明書をよく読んでから始めてください。詰まった雪を取るときは、**必ずエンジンを止め、回転が止まってから**雪かき棒などの道具で取り除いてください。

## よくある質問

**Q. 個人で除雪機を買ったら、札幌市の補助は出る？**
A. 出ません。札幌市の小型除雪機購入費の補助は、町内会と除雪ボランティアを行う団体が対象で、個人と企業への補助は行っていないと案内されています。

**Q. 町内会で買えば、いくら補助が出る？**
A. 本体価格（消費税込み）の2分の1以内で、上限は50万円です。オプション部品や配送料は対象外です。中古品や個人売買で買ったものは対象になりません。

**Q. 買ったあとに申し込んでもいい？**
A. できません。購入する2週間以上前に申し込む必要があり、交付が決まる前に買った場合は補助金が出ないと案内されています。
