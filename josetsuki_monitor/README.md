# 除雪機ネット 在庫チェック

GitHub Actions が毎朝8時ごろ（日本時間）に除雪機ネットの「ロータリータイプ」一覧を読み、前回から数量・価格・表示・人気ランキングが変わったときだけ Issue を作って通知します。公開リポジトリの GitHub Actions は無料です。

- 追跡する機種: `config.json` の `watch`（型番の一部。`YT660` は `YT660B` を含みません）
- 一覧ページへのたどり方: `nav`（リンク文字を順にクリック）。たどれなくなったら `list_url` に一覧ページのURLを直接入れる
- 前回の状態: `state.json`（変化があった日だけ自動で更新・コミット）
- 取得に失敗した日はワークフローが失敗し、GitHub から失敗メールが届きます
