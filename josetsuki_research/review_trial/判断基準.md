# 複数AI審査の試行：判断基準（実行前に固定、2026-10-18）

## 対象と選んだ理由
- 記事：北海道の除雪機 在庫・価格まとめ（/entry/2026/10/05/210159）。原稿は `original.md`（10/17版＋ボタン化）
- 理由：全記事の「あわせて読みたい」の先頭、チャンネルのリンク先（10/17変更）で、今後いちばん人が集まる記事。販売ページへのボタンが8つあり、成約に一番近い
- 60cm比較は効果が大きい可能性があるが、手元の原稿が古いため今回は対象外

## A. 工程の判定（実行直後に判定できる）
| 指標 | 合格の基準 |
|---|---|
| A1 実質的な改善の数 | 根拠つきで採用された指摘が3件以上。うち「通常の私の見直しでは出なかった」と言えるものが1件以上 |
| A2 事実の誤りの発見 | 誤り・古い情報を見つけた場合、すべて出典（公式・販売ページの記録）つきで直っている |
| A3 改悪ゼロ | 最終監査で「新たな誤り」「ルール違反（STRATEGY 6章・blog.md）」「スマホでの読みにくさの悪化」が0件 |
| A4 根拠のない採用ゼロ | 採用した修正すべてに、根拠（データ・公式・ルール・読者の行動）が書かれている |
- 4つすべて満たせば「工程は有効」。A3を満たさなければ、修正版は使わない

## B. 成果の判定（公開から3週間後、11月上旬）
| 指標 | 見る場所 | 基準 |
|---|---|---|
| B1 クリック率 | GA4探索「店へのクリック」：この記事から除雪機ネットへのclick÷この記事の表示回数（GA4の「click」合計は記事間の移動を含むので使わない） | 公開前4週間（9/21〜10/18：店へのクリック3回）と比べて上がる |
| B2 読まれ方 | GA4：この記事の平均エンゲージメント時間・scroll | 下がらない |
| B3 検索 | Search Console：この記事の表示回数・平均掲載順位 | 下がらない |
- **比較対照**：同じ時期にボタン化だけした記事（買ってはいけない・静音2台・通販4つ・札幌補助金）。対象記事の伸びが対照より大きいかを見る（ボタン化の効果と区別するため）
- **サンプル数の条件**：この記事の表示が3週間で50回未満なら、Bは「判定不能」とし、Aの結果だけで続けるかを決める（10/16時点で28日6回のため、判定不能になる可能性が高い）
- 公開前の値（ベースライン）は、10/19の週次チェックのGA4画面で記録する

## C. 続けるかの判断
- Aが合格 → 柱の記事（在庫まとめ・買ってはいけない・60cm・70cm）に月1回ずつ使う
- Aが不合格 → 通常の見直しに戻す。どこが弱かったか（審査役の指示、調べられる範囲など）を記録する
- かかった時間と手間も記録する（通常の修正との比較）
