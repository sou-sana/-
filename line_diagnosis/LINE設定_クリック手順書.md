# LINE診断の設定 ― クリック手順書

所要時間:約40分。PCのブラウザで LINE Official Account Manager を開いて作業する。
**上から順番に**やる(リッチメッセージを先に作らないと、応答メッセージで選べないため)。

準備:この会話に添付した画像 `Q1.png` `Q2.png` `Q3.png` `Q4.png` を、PCにダウンロードしておく。

---

## ステップ1:応答メッセージを使える状態にする(1分)

1. 左メニュー下の **「設定」** → **「応答設定」**
2. 「応答機能」の **「応答メッセージ」をオン** にする
   (「チャット」はオフのままでよい。「あいさつメッセージ」もオン)

---

## ステップ2:リッチメッセージを4つ作る(各5分)

左メニュー **「メッセージアイテム」→「リッチメッセージ」→「作成」**

| 入れる場所 | Q1 | Q2 | Q3 | Q4 |
|---|---|---|---|---|
| タイトル | 診断Q1 | 診断Q2 | 診断Q3 | 診断Q4 |
| 画像 | Q1.png | Q2.png | Q3.png | Q4.png |
| 左下(はい)のテキスト | A1はい | A2はい | A3はい | A4はい |
| 右下(いいえ)のテキスト | A1いいえ | A2いいえ | A3いいえ | A4いいえ |
| 上の領域のテキスト | 診断スタート | A1いいえ | A2いいえ | A3いいえ |
| トークルーム通知テキスト | 辞めどきチェック 質問1 | 質問2 | 質問3 | 質問4 |

操作:
1. **「テンプレートを選択」** → 上に1つ・下に2つ並んだ **3分割** の型を選ぶ
2. **「背景画像をアップロード」** → Qn.png を選ぶ
3. A・B・C の各領域で、アクションのタイプを **「テキスト」** にして、上の表の文字を **一字一句そのまま** 入れる
   - どれがA/B/Cかは、画面のプレビューで位置を見て合わせる(上=質問、左下=はい、右下=いいえ)
4. **「保存」**

> 3分割の型が見つからない場合:左右2分割の型を選び、左=はい・右=いいえだけ設定する(質問文は画像の上半分に書いてあるので、そのまま読める)

---

## ステップ3:応答メッセージを9つ作る(各2分)

左メニュー **「自動応答」→「応答メッセージ」→「作成」**。毎回この流れ:

1. タイトル:下の表の「タイトル」
2. **キーワード** に下の表の文字を入れる(「診断スタート」の行だけ、「診断」も追加して2つ登録)
3. メッセージ欄:
   - 「リッチメッセージ」と書いてある行 → メッセージの種類で **「リッチメッセージ」** を選び、ステップ2で作ったものを選択
   - 「文面」と書いてある行 → **「テキスト」** を選び、`辞めどき4段階チェック_LINE診断_設計と全文面.md` の該当する文面を丸ごと貼る
4. **「保存」**(ステータスがオンになっているか確認)

| タイトル | キーワード | メッセージ |
|---|---|---|
| 診断開始 | 診断スタート / 診断 | ①テキスト:文面「診断スタート(導入文)」 ②リッチメッセージ:診断Q1 (吹き出しを「追加」で2つにする) |
| Q1はい | A1はい | 文面「結果:段階4」 |
| Q1いいえ | A1いいえ | リッチメッセージ:診断Q2 |
| Q2はい | A2はい | 文面「結果:段階3」 |
| Q2いいえ | A2いいえ | リッチメッセージ:診断Q3 |
| Q3はい | A3はい | 文面「結果:段階2」 |
| Q3いいえ | A3いいえ | リッチメッセージ:診断Q4 |
| Q4はい | A4はい | 文面「結果:段階1」 |
| Q4いいえ | A4いいえ | 文面「結果:安定」 |

> 応答メッセージでリッチメッセージを選べなかった場合:その行は「テキスト」にして、次の質問文と「『A2はい』か『A2いいえ』と送ってください」のように案内する(手入力になるが動く)

---

## ステップ4:あいさつメッセージ(友だち追加の直後に届く文)(3分)

左メニュー **「トークルーム管理」→「あいさつメッセージ」** → 本文を下に置き換えて **「変更を保存」**

```
{AccountName}を友だち追加いただき、ありがとうございます。

ここでは、看護師の「辞めどき」と働き方を、
心理学と行動経済学の視点から言葉にしています。

まずは、いまの自分が「辞めどき」のどの段階にいるか、
確かめてみませんか?

質問は最大4つ、1分で終わります。
↓このトークに「診断」と送ってください。
```

`{AccountName}` は画面の「アカウント名」ボタンで挿入される(手で打たなくてよい)。

---

## ステップ5(任意・あとでよい):リッチメニューに診断ボタン(10分)

左メニュー **「トークルーム管理」→「リッチメニュー」→「作成」** → テンプレートで1ボタンの型 → アクション「テキスト」=「診断スタート」。画像は後で作るので、まずは飛ばしてよい。

---

## ステップ6:テスト(5分)

1. 自分のスマホのLINEで、このアカウントを友だち追加する(友だち追加ガイドのQRから)
2. 「診断」と送る → 導入文+質問1が出るか
3. 5ルートを全部試す
   - はい → 段階4
   - いいえ→はい → 段階3
   - いいえ→いいえ→はい → 段階2
   - いいえ×3→はい → 段階1
   - いいえ×4 → 安定
4. 反応しないときは、キーワードの文字(全角・半角、スペース)が表と完全に同じかを確認する
