# げんばのカルテ 本編2(横 1920×1080)

完成動画: `outputs/辞めたいのに言い出せない_げんばのカルテ本編2.mp4`(1920×1080 / 30fps / H.264 + AAC / 5分01秒)

## 再生成
```sh
../genba_karute_shorts/setup_voicevox.sh   # VOICEVOX(剣崎雌雄)一式。vv は ../genba_karute_shorts/vv へのリンク
pip install pillow numpy scipy --break-system-packages
python3 make_images.py && ./render.sh      # img01〜18.svg → png(差し替え画像があるなら KEEP_PNG=1 ./render.sh)
python3 build.py                           # storyboard.json → outputs/<title>.mp4(約5分の書き出し)
```

## 仕様(build.py / storyboard.json)
- ナレーション: VOICEVOX 剣崎雌雄(ノーマル)、話速0.92・音高-0.03・抑揚0.81。一文ずつ合成し、文間1.3秒・シーン間2.5秒の間
- 字幕: シーンの「字幕」行を、画面下の全幅濃紺(#0F2A3D)帯+白文字(Noto Sans CJK JP Bold 52px)で、そのシーンの間ずっと表示
- 画像: 1枚あたり7〜32秒。0.8秒クロスフェード+4%のごく緩いズーム
- 冒頭2秒に右上「PR」テロップ。最後の10秒はエンドカード(⑱)に「げんばのカルテ / 無料チェックはLINEから / 相談は概要欄」
- BGM: `make_piano_bgm.py` が合成する静かなピアノ(外部素材なし)。ナレーション比 -18dB
- 音量: -16 LUFS

## 指示書との違い
- **画像はすべてフラット(顔なし)**。スタイルA(表情ありの半リアル)の場面も、いまはフラットのイラストで代用している。Canvaは4枚生成したところでクレジット上限に達し、しかも画像をダウンロードする手段がない。ほかの画像生成サービスもネットワークでブロックされている。A画像を用意したら `img01.png` のように番号どおりに置き、`python3 build.py` で差し替わる(スタイルAは ①②⑤⑥⑦⑧⑨⑩⑪⑫⑬⑰)。
- **尺**は約5分01秒。台本のナレーションは話すと約3分なので、話速を少し落とし、間を長めに取って5分台に収めている。

## 事実確認
- 「利用者の約半数は在籍3か月未満」: 退職代行利用者4,963人のアンケートで53%(PR TIMES, 2024)。別のパーソル総合研究所の調査では「1年未満」が約4割。
- 「申し出から2週間で辞められる」: 民法627条1項(期間の定めのない雇用)。有期契約の場合は原則として期間満了まで(やむを得ない事由があれば即時)。
