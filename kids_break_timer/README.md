# やすみタイマー（子どものAndroid用 使用時間制限アプリ）

画面を使った時間が **45分** に達すると、**15分** のあいだ画面全体を「おやすみタイム」で覆って操作できなくする。休憩が終われば自動で解除され、また45分使える。時間は保護者画面で変更できる。

## 動き

- 数えるのは「画面ON かつ ロック解除中」の時間だけ。画面OFFの時間は数えない
- 画面OFFが15分以上続いたら、休んだとみなして使用時間を0に戻す
- 休憩は実時間で15分。再起動しても休憩の残りは保持される
- 残り5分と1分で「あと○分で休憩です」と表示する
- 休憩画面の「保護者」ボタンでパスワードを入れると、すぐ解除できる

## インストール手順（子どものスマホで）

1. `release/yasumi-timer-1.0.apk` を子どものスマホに入れる（GitHubから直接ダウンロード、またはGoogleドライブ経由など）
2. ファイルをタップしてインストールする。「提供元不明のアプリ」の許可を求められたら許可する。Play プロテクトの警告が出たら「詳細」→「インストールする」を選ぶ
3. 「やすみタイマー」を開き、保護者パスワードを決める
4. 「必要な許可」をすべて ✅ にする
   - 他のアプリの上に重ねて表示
   - 通知
   - 電池の最適化をしない
   - 端末管理アプリ（「制限付き設定」と出たら、設定 → アプリ → やすみタイマー → 右上の︙ → 「制限付きの設定を許可」をしてから再度）
5. 「見守りを開始する」を押す
6. ファミリーリンクを使っているなら、ファミリーリンク側で「提供元不明のアプリ」のインストールを禁止しておく

## 限界（正直なところ）

- 使える時間中に、子どもが 設定 → アプリ → やすみタイマー →「強制停止」をすると、次の再起動まで止まる。端末管理アプリにすると**削除**は防げるが、強制停止までは防げない
- セーフモードで起動すると停止する
- 休憩中も通知パネル（上からのスワイプ）は開ける
- 休憩中でもロック画面は覆わないので、電源ボタン → ロック画面の「緊急通報」から電話できる（ロックを解除すると休憩画面に戻る）

小学生くらいまでの「ルールを守る仕組み」として使う想定。抜け道を探す年齢の子には、ファミリーリンクの1日の上限と併用するのがよい。

## ビルド（開発者向け）

```bash
gradle testDebugUnitTest assembleDebug lintDebug
```

`local.properties` に `sdk.dir=<Android SDKのパス>` が必要。デバッグ署名なので、別のPCでビルドし直したAPKは上書きインストールできない（一度アンインストールが必要）。
