# 情報収集

## 情報源と確度
| 区分 | 情報源 | 使い方 | 確度 |
|---|---|---|---|
| メーカー公式 | Honda（honda.co.jp/snow、global.honda/jp/news）、ヤマハ（yamaha-motor.co.jp/snowblower）、Willbe（willbe-corp.com/products/earthpower、snowblower.willbe-corp.com）、Wado（wadosng.jp） | 仕様（最大出力・除雪幅・除雪高・重量・装備）、事業の動き | 確実 |
| 業界団体 | 日本建設機械施工協会の小型除雪機一覧PDF | 公式が見つからない仕様の補助 | ほぼ確実（出典を書く） |
| 販売先 | 除雪機ネット（在庫監視 `josetsuki_monitor/`、販売ページ） | 価格・在庫表記・売り切れ | 掲載どおりに書く |
| 公的機関 | 気象庁・札幌管区気象台（寒候期予報・初雪）、札幌市など自治体（補助金・支援制度） | 季節の企画、補助金 | 確実（年度を書く） |
| 販売店 | YSP札幌清田、YSP富山、茨城建機など | 公式にない運用情報（修理継続など） | 「販売店の告知では」と書く |
| 競合・参考サイト | 雪ブンブン、マイベスト、Picky's、GardenMachineLab、Monita、唐沢農機、農機具高く売れるドットコム ほか | 構成・切り口・検索需要のヒント。数字は使わない | 参考のみ |
| 読者の声 | YouTubeコメント、Yahoo!知恵袋、Search Consoleのクエリ | 企画の種、記事の補強 | 需要の確認 |

## 手順
1. 公式を先に探す（WebSearch。WebFetch・curlは多くのドメインが環境の制限で失敗するので、検索結果の抜粋で確認する。ユーザーに貼ってもらうのも可）
2. 2つ以上の情報源で一致したら「確実」。販売店・解説記事だけなら「未確認」としてSTRATEGYに書き、使わないか出典つきで使う
3. 数字は条件ごと記録する（例：除雪高 新雪51cm／最大目安60cm／固まった雪35cm、出力 9.4PS@3,600rpm）
4. 参考サイトを分析したら、STRATEGY 9章に「取り入れる（ブログ・動画での使い方）／取り入れない（理由）」の表で追記する。判断基準は「スマホでYouTubeから来た人が、除雪機ネットの在庫ページを押すまでが短くなるか」
5. 確認できた事実・未確認の事実を、企画ごとにSTRATEGYに残す（例：キュー3番の確認済み事実の表）

## 頻度
| 対象 | 頻度 | きっかけ |
|---|---|---|
| 在庫・価格（除雪機ネット） | 毎日（自動。変化があればIssueとメール） | 通知メール |
| メーカー公式（新製品・仕様・事業の動き） | 企画を作る前に必ず＋月1回まとめて | 新企画、コメントでの指摘 |
| 気象（寒候期予報・初雪・大雪の予報） | 10〜12月は週1回、大雪予報が出たら当日 | 「暖冬でも必要？」「大雪前に」企画 |
| 自治体の補助金・支援制度 | 月1回（11月までに2026年度分を確認） | キュー5番 |
| 競合・参考サイト | 月1回、上位5サイトを見る（ユーザーが貼った時はその都度） | 新しい切り口・弱点の発見 |
| YouTubeコメント | 投稿後2日間は毎日、その後は週1回 | 誤りの指摘・質問 |
| Search Consoleのクエリ | 週1回（月曜） | 記事の追記・新企画 |
