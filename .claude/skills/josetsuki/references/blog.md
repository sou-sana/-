# ブログ記事（はてなブログ・Markdownモード）

## 記事の型（この順で）
1. 先頭の行（貼り付け時に消す）：タイトル案／カテゴリー／**記事の概要（必須。毎回、編集オプションの「記事の概要」に貼る。120字前後で、答え＋数字＋対象を入れる）**／貼り方の注意
2. PR表記：「当サイトでは、商品の紹介・比較にアフィリエイト広告を利用しています。…」→ 直後に「このサイトについて」の枠（紺の枠、札幌在住・公式の数字と毎日の在庫・実機テストなし・更新履歴）
3. `**最終更新：YYYY年M月D日**`（価格・在庫の基準日も書く）
4. 「この記事でわかること」（引用の中の箇条書きは下の書き方）
   ```
   > **この記事でわかること**
   >
   > - …
   ```
5. 先に結論（表か3つの要点）
6. 本文：数字は公式の値と条件・出典。推測は「（推測）」
7. 今買える機種の表（**3列まで**：機種・除雪幅・価格。スマホで崩れないため）＋機種ごとの「向く人」1行＋**オレンジのボタン**（下のHTML）＋送料の注記1行
8. 在庫・売り切れの一言（今季すでに売り切れた機種も書く）
9. 「## あわせて読みたい」（全記事で同じ形。**先頭は必ず在庫まとめ**、続けて買ってはいけない・60cm比較・70cm比較・通販4つから自分以外、最後にテーマの近い記事1本。計5本前後。スマホではサイドバーが出ないため、記事内のこの節が唯一の回遊導線）
10. 安全の一言（詰まりはエンジンを止めてから道具で）
11. よくある質問（2〜3問）
12. 注記：仕様は公式、価格・在庫は除雪機ネットの掲載情報、実機テストはしていない、誤りはコメントで
13. 参考情報（公式ページへのリンク）

## カテゴリー（10/16決定。はてなは1記事に複数つけられる）
| カテゴリー | 入れる記事 |
|---|---|
| 在庫・価格 | 在庫まとめ |
| 選び方の基本 | 何馬力必要／6・8・10馬力／60・70・80cm／買ってはいけない |
| 機種比較 | 60cm比較／70cm比較／ハイブリッド／静音2台／ヤマハ・Willbe |
| 買い方・補助金 | 通販で買う前に店に聞く4つ／札幌補助金／ヤマハ・Willbe（修理・保証の窓口） |
固定ページ（このブログについて・お問い合わせ・プライバシーポリシー）にはつけない。新しいカテゴリーを増やすのは、同じ種類の記事が3本以上になってから。
タイトル欄に「タイトル：」を入れない（下書きの1行目はタイトル案なので、文言だけをタイトル欄へ）

## 販売ページへのボタン（10/18〜全記事これ）
```
<a href="（商品URL）" style="display:block;background:#f26b0f;color:#fff;text-align:center;padding:14px 8px;border-radius:8px;font-weight:bold;text-decoration:none;margin:10px 0;">（型番）の価格と在庫を見る（除雪機ネット）</a>
```
- ボタンとボタンの間は空行を入れる。最初のボタン群の下に「※ボタンの先は除雪機ネットの販売ページです。表示価格は本体価格で、北海道は送料が別にかかります（札幌市まで営業所止めで約6万円の例。2026年10月の問い合わせ）。」
- 「このサイトについて」の枠：
```
<div style="border:2px solid #0d2a47;border-radius:8px;padding:10px 12px;margin:12px 0;font-size:90%;line-height:1.7;"><strong>このサイトについて</strong>：札幌在住の運営者が、メーカー公式の数字と、毎日チェックしている在庫情報で除雪機を比べています。実機テストはしていません。送料や在庫は日付つきで書き、間違いは更新履歴に残して直します。</div>
```
- 運営者の事実：札幌在住、除雪機の使用経験なし（使った経験を書かない）。表示名は「北海道の除雪機選び」

## アイキャッチ画像
- 記事ごとに1枚（1200x630）。`josetsuki_video/make_eyecatch.py` の ITEMS に足して作る（写真＋紺のグラデーション＋見出し2行＋右下に※イメージ）。横動画があるテーマはそのサムネイルを流用
- はてなの編集画面で画像を本文に入れず、「編集オプション」→「アイキャッチ画像」で指定する（本文の先頭に画像を置くと、スマホで結論が下がるため）

## リンク
- 商品：`https://josetsuki.net/catalog/product_info.php?ref=37&products_id=<ID>&affiliate_banner_id=1`（IDは STRATEGY 3章）
- 全体：`https://josetsuki.net/catalog/index.php?ref=37&affiliate_banner_id=71`
- 動画から記事へのリンク：`?utm_source=youtube&utm_medium=video|comment|channel&utm_campaign=<テーマ>`
- 売り切れの機種はリンクを外して代わりの機種を書く

## 書いてはいけないこと
- 除雪機ネットの表記と公式を並べて「違う」と見せる書き方
- 店の規約・サービスの説明を記事やショートの主役にすること（「例：除雪機ネットの場合」として引用する）
- 販売ページにない「残りわずか」、在庫1台・展示機を主役にすること
- 出典のない目安（「車2台分なら50〜70cm」など）、他サイトの文章・口コミの転載

## 公開後の作業
1. ユーザーからURLをもらい、STRATEGY 3章に記録（はてなのURLは投稿日時：/entry/YYYY/MM/DD/HHMMSS）
2. Search Consoleで「URL検査」→「インデックス登録をリクエスト」
3. 関係する既存記事と横動画の概要欄・固定コメントに、新記事へのリンクを足す文面を渡す（全文差し替え版）
4. 下書きファイル `josetsuki_blog/<名前>.md` をユーザー公開版に合わせて更新

## 在庫が変わったとき（通知メール・Issue）
- 在庫まとめ記事の表と「最近の更新内容」を更新（日付つき）
- 該当機種を扱う記事：売り切れ表記・リンク削除・代わりの機種
- 動画：説明欄に更新文、固定コメントに追記
