# 北海道の除雪機選び：制作・運用スキル

目的：2026-27シーズンに、除雪機ネット（ref=37、報酬2%）経由の最初の成約を出す。

## 最初にやること
1. `josetsuki_STRATEGY.md` を読む（今の数字・資産・URL・商品ID・制作キュー・過去の失敗）。**事実と状態はSTRATEGY、手順はこのスキル**
2. 依頼の種類で、読む参照ファイルを選ぶ

| 依頼 | 読むファイル |
|---|---|
| 調べる・参考サイトを読む・仕様を確かめる | `references/research.md` |
| ショート・横動画を作る、画像プロンプトを出す | `references/video.md` |
| ブログ記事を書く・直す・在庫を更新する | `references/blog.md` |
| 数字を読む、何をいつ確認・更新するか | `references/operations.md` |

## 動かさない方針
- 導線：ショート → 関連動画（横動画）→ 概要欄・固定コメント・チャンネルのリンク → 記事 → 除雪機ネット
- 主役は北海道の家庭用エンジン機（40〜90万円）。電動・海外製の安価機は主役にしない
- 出口は除雪機ネットだけ。楽天は上限1,000円/商品のため使わない（STRATEGY 3-2）
- 差別化は「日付つきの在庫・売り切れ情報」と「公式で確認した数字」。競合はここが弱い

## 絶対に守ること（詳細はSTRATEGY 6章）
- 数字は公式で確認してから使う。確実／推測／不明を書き分ける。捏造しない
- 基準の違う数字を並べない（区分名「〇馬力帯」と最大出力、測定回転数、除雪高の新雪値と最大目安）
- 除雪機ネットの表記と公式を並べて「違う」と見せない。比較は公式どうしで完結させる
- 在庫1台・展示機を主役にしない。在庫表記は販売ページの表示どおり
- PR表記（記事冒頭・動画冒頭テロップ・説明欄）、「有料プロモーション」、音声クレジット、機体画像の「※イメージ」、ロゴ・ナンバーのぼかし
- コピーしたURLに `utm_source=chatgpt.com` が付いていないか確認
- ユーザーへの返答：結論先出し、貼り付け用の文面は全文（部分修正にしない）、コピペ1回で済む形

## 作業の終わりに
- 作った記事・動画・投稿文はリポジトリに保存し、commit・push
- 公開URL、数字、新しく分かった事実、ルールの追加は `josetsuki_STRATEGY.md` に反映
- 次にユーザーがやること（投稿・URL検査・確認する画面）を短く伝える
- ユーザーが動画を投稿したら `josetsuki_reminders/posts.json` に追記してcommit（投稿後チェックのリマインドが届く）
- ユーザーがリマインドのIssueに沿ってスクリーンショットを送ってきたら、operations.md の「動く基準」で判断し、STRATEGYの数字を更新する
